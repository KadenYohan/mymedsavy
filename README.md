# MyMedSavy

Medication safety web app built with React, Vite, TypeScript, Tailwind CSS, and Supabase.

## Local development

1. Install dependencies:

```sh
npm install
```

2. Start the development server:

```sh
npm run dev
```

3. Open the app at the URL shown by Vite.

## Build and preview

Build for production:

```sh
npm run build
```

Preview the production build locally:

```sh
npm run preview
```

## Tests

Run test suite:

```sh
npm run test
```
